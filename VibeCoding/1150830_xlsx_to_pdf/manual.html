📖 使用手冊

三種轉檔方式，依你的環境挑一種即可

🌐 方案 A：線上轉檔網頁版任何瀏覽器

純前端運作，不需要安裝 Office，適合只需要表格數值、不需要 100% 還原統計圖表/流程圖的情境。

  1. 直接以任一瀏覽器雙擊開啟 converter.html（或從首頁點「線上試用」）。
  2. 將 Excel 檔案（.xlsx / .xls / .csv）拖曳至網頁放置區，或點擊放置區選檔。
  3. 系統會自動修剪無效空白邊界，並預設載入「📑 全部工作表」。
  4. 點選「🖨️ 列印 / 另存為 PDF」，在瀏覽器列印對話框中選擇「另存為 PDF」即可完成。
限制：純前端解析無法重繪 Excel 原生的統計圖表 (Charts) 與 SmartArt 流程圖，這兩種內容需要用方案 B。

🪟 方案 B-1：Windows 原生腳本Windows

呼叫本機已安裝的 Excel 引擎匯出，100% 還原圖表與流程圖，零安裝、免系統管理員權限。

  1. 下載 拖曳Excel至此轉PDF_Windows版.zip，解壓縮後會得到 拖曳Excel至此轉PDF.bat，放到桌面或放有 Excel 檔案的資料夾。
  2. 選取一個或多個 Excel 檔案，直接拖曳放到該 .bat 圖示上方。
  3. 系統會在背景靜默呼叫 Excel 原生引擎，自動於同目錄產出標準 PDF。
  4. 沒有東西可拖曳時，直接雙擊執行：若當前目錄找不到任何 Excel 檔案，會自動跳出 Windows 的「開啟檔案」對話框，讓你直接選檔（可一次選多個）。
需求：這台電腦要已安裝 Microsoft Excel（腳本是呼叫本機既有的 Excel，不會另外下載安裝任何東西）。
若跳出「Windows 已保護您的電腦」提示：這是 SmartScreen 對「不常見下載」的正常警示（因為這是全新、下載次數少的檔案），不是病毒偵測。點選視窗中的「其他資訊」，再點「仍要執行」即可繼續。若檔案圖示上有鎖頭符號、或直接被瀏覽器擋下無法下載，可在檔案上按右鍵 →「內容」→ 勾選最下方的「解除封鎖」→ 確定，再重新執行。

🍎 方案 B-2：macOS 原生腳本macOS

呼叫本機已安裝的 Excel（透過 AppleScript）匯出，100% 還原圖表與流程圖，零安裝、免系統管理員權限。

  1. 下載 拖曳Excel至此轉PDF.command，放到桌面或放有 Excel 檔案的資料夾。
  2. 雙擊執行，會自動轉換同目錄下的 Excel 檔案；或直接把 Excel 檔案拖到程式圖示上執行。
  3. 系統會呼叫 macOS 上的 Excel 原生引擎，於同目錄產出標準 PDF。
  4. 若當前目錄找不到任何 Excel 檔案，會自動跳出 Finder 的「選擇檔案」對話框，讓你選檔（可一次選多個）。
首次執行提醒：macOS 會跳出「是否允許控制 Microsoft Excel」的系統對話框，請點選「允許」，之後就不會再問。

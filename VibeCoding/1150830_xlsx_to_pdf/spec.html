核心實作邏輯

trimWorksheetBounds()：遍歷工作表非 meta 鍵值，動態計算含值儲存格的最小/最大行列，重寫 ws['!ref']，避免 Excel 虛標的 256 欄位產生大量無效空白 <td>。

sanitizeSheetHtml()：用 DOMParser 惰性解析 sheet_to_html() 輸出，以標籤/屬性白名單過濾後才掛進真正 DOM，防止惡意 xlsx 夾帶的標籤/事件屬性被執行（詳見資安檢測報告）。

Windows 端用 PowerShell 呼叫 Excel.Application COM 物件的 ExportAsFixedFormat；macOS 端用 osascript 呼叫 AppleScript 操作 Microsoft Excel 的 save workbook as ... file format PDF file format。

# PRD 13 — 圖片批次最佳化工作台
- **英文短名稱**：`image-batch-optimizer`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/image-batch-optimizer/`

### 為什麼做
Email、LINE、上傳系統常限制圖片容量；使用者真正想要的是「壓到 1MB 以下」，不是研究 quality slider。

### MVP
- JPG/PNG/WebP 批次匯入。
- 格式轉換。
- 長邊／寬高限制。
- 保持比例。
- 目標容量：1MB、2MB、自訂。
- 自動逐步調整品質，必要時降低尺寸。
- 顯示原始／輸出容量。
- 個別下載／ZIP。
- 預設不放大小圖。

### 驗收條件
- 情境：目標 1MB 時盡力產出 <=1MB；無法達成時明確提示。
- 情境：批次輸出保持原檔對應關係。
- 情境：預設不拉伸圖片比例。

# PRD 02 — PDF_TO_JPG 重製版
- **英文短名稱**：`pdf-to-jpg`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-to-jpg/`

### 為什麼做
政府公文、掃描檔、合約書常為多頁 PDF，在社群分享、簡報插入或圖片標註時需要逐頁轉成高畫質 JPG。

### MVP
- 上傳多頁 PDF。
- 逐頁預覽縮圖。
- 品質滑桿調整。
- 逐頁非同步渲染轉成 JPG。
- 支援單頁獨立下載。
- 支援一鍵打包所有頁面為 ZIP 下載。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：10 頁 PDF 產生 10 張 JPG。
- 情境：可只下載指定頁。
- 情境：全部下載時得到含所有頁面的 ZIP。
- 情境：離線 HTML 仍可轉換。

# PRD 18 — PDF 拆分 / 合併 / 重排工作台
- **英文短名稱**：`pdf-organizer`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-organizer/`

### 為什麼做
整理跨部門報告、標案文件或合約附件時，經常需要將多份 PDF 依指定順序抽取合併、旋轉方向、刪除多餘空白頁，或將一份長文件拆分為多組不同用途的 PDF 檔案。

### MVP
- 批次匯入多份 PDF 檔案。
- 逐頁視覺化縮圖預覽（標示所屬檔案與原頁碼）。
- 原生指針拖曳（Pointer-based Drag & Drop）自訂頁面順序。
- 單頁旋轉（90° 步進）與標記刪除／還原。
- 支援建立多個輸出群組（1 組產出單一 PDF，多組產出多份 PDF 並打包為 ZIP）。
- 實時保留頁數與群組統計。
- 純前端執行，原始檔案不被修改。

### 驗收條件
- 情境：可將不同 PDF 指定頁重新組成新 PDF。
- 情境：刪除與旋轉結果正確反映在輸出。
- 情境：來源檔案保持不變。
- 情境：拖曳排序操作不會造成頁面來源錯位。
- 情境：輸出群組數量為 1 時直接下載 PDF，>1 時每組各自產出 PDF 並包成 ZIP。

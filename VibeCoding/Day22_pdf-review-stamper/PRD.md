# PRD 20 — PDF 頁碼 / 浮水印 / 送審章
- **英文短名稱**：`pdf-review-stamper`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-review-stamper/`

### 為什麼做
送審、核定、會簽公文或合約草案時，常需在每頁加上審查章（如「草稿」、「密件」、「僅供參考」）與頁碼（如 `1/10`）。

### MVP
- 上傳多頁 PDF。
- 支援頁碼設定（頁首 / 頁尾，`X` 或 `X/Y` 格式）。
- 支援 4 種常用預設送審文字（草稿、密件、僅供參考、未核定）及自訂文字輸入。
- 支援中文浮水印嵌入（內嵌 Noto Sans TC 中文字型）。
- 支援透明度（預設 50%）、旋轉角度（預設 45°）、位置（左上、置中、對角線）調整。
- 支援套用範圍設定（全頁或指定頁碼範圍）。
- 提供按鈕觸發式即時頁面預覽。
- 匯出加工後的 PDF 檔案。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：指定第 2–5 頁時其他頁不加標記。
- 情境：`X/Y` 的 `Y` 為輸出總頁數。
- 情境：使用者可先預覽再下載。
- 情境：中文浮水印文字正確顯示無缺字。
- 情境：原始上傳檔案不被覆寫。

# PRD 23 — PDF 安全遮蔽 / Flatten
- **英文短名稱**：`pdf-secure-redactor`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-secure-redactor/`

### 為什麼做
直接在 PDF 上畫黑色矩形覆蓋文字（如使用預覽程式加黑色方塊），底層文字層依然存在，複製貼上即可輕易復原敏感個資。真正的遮蔽必須徹底銷毀被遮蔽區域的底層文字（點陣化 Flatten）。

### MVP
- 上傳多頁 PDF 檔案。
- 支援逐頁預覽與互動式矩形拖曳框選遮蔽區域。
- 支援一頁多重遮蔽框與個別刪除。
- 支援遮蔽顏色切換（純黑 #000000、純白 #ffffff、灰色 #808080）。
- 選擇性點陣化（Selective Rasterization）：僅對有遮蔽框的頁面以 2.0x 渲染為點陣圖銷毀文字層；無遮蔽頁面原樣保留向量文字。
- 清楚標示每頁狀態（點陣化遮蔽 vs 原樣保留）。
- 匯出遮蔽後的安全 PDF 檔案。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：遮蔽區域底層文字完全被點陣化覆蓋，文字搜尋與複製皆無法取得。
- 情境：未遮蔽頁面原樣保留，文字層完整可搜尋。
- 情境：原始檔案保持不變。

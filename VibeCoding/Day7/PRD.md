# Day 3 PRD — 文字差異比對器

> 🔀 **本內容原編號 Day3，因系列重新分類移至現在的 Day7。**

> 交付類型：**A 類**（GitHub Pages／下載 HTML，純前端執行，唯一例外是需內嵌 jsdiff 函式庫做差異比對，不上傳任何內容到伺服器）

---

## 1. 背景與痛點

### 主情境：合約／公文改版比對（銜接 Day2 PDF 轉 TXT/MD）

承辦人員收到廠商／對方寄來的合約、公文修訂版，兩份文件內容相近但改了幾處條款，肉眼逐字比對容易漏看、也容易看錯。若原始檔案是 PDF，通常會先用 Day2 的工具轉成乾淨的純文字或 Markdown，再貼進本工具比對兩版差異，兩篇文章的情境前後呼應。

### 延伸情境：一般文件版本比對

規章、公告、SOP 等文件每次修訂後，承辦人員需要跟前一版比對「到底改了哪幾句」，才能在會議或簽核時說明修訂重點，手動比對耗時且容易遺漏。

## 2. 目標使用者

- 主要：一般辦公室行政人員、承辦人員，不具備程式背景
- 次要：需要比對文件版本差異的一般使用者（規章、SOP、公告）

## 3. 使用情境（User Story）

1. 身為要比對合約修訂版的承辦人員，我把舊版與新版文字分別貼進左右兩欄（或直接拖曳 Day2 轉出的 .txt/.md 檔），就能立刻看到哪些句子被刪除、新增或修改，不用逐字對照。
2. 身為要跟主管報告修訂重點的承辦人員，我想先看到「未變動的段落自動收合」的畫面，只聚焦在真正改動的地方，減少閱讀干擾。

## 4. 功能需求（MVP，本次必須完成）

| # | 功能 | 說明 |
|---|---|---|
| F1 | 雙欄文字輸入 | 左欄「舊版」、右欄「新版」，皆可直接貼上文字 |
| F2 | 拖曳 .txt/.md 檔案 | 左右兩欄各自支援拖曳單一 .txt 或 .md 檔案，自動讀取內容帶入該欄 |
| F3 | 逐句斷句 | 依段落（換行）分塊，段落內再依中文句尾標點（。！？；）分句作為比對最小單位；無標點的整段視為一句 |
| F4 | 差異比對 | 用內嵌 jsdiff 函式庫對兩份句子陣列做差異比對，標出新增、刪除、修改（視為刪除＋新增的配對） |
| F5 | 並排左右對照顯示 | 左欄舊版、右欄新版逐句對齊顯示；新增句底色標示、刪除句底色標示、修改句雙欄皆標示 |
| F6 | 未變動區塊摺疊 | 連續 3 句以上未變動的區塊預設摺疊為一行「未變動 N 句（點擊展開）」，可個別展開或一鍵全部展開 |
| F7 | 差異統計摘要 | 顯示「新增 X 句／刪除 X 句／修改 X 句／未變動 X 句」 |
| F8 | 複製與下載 | 一鍵複製差異摘要文字；一鍵下載 Markdown 格式的差異報告 |

## 5. 非必要／可延伸功能（Nice to have，非 Day3 範圍）

- 句內字元級差異標色（目前僅整句標色，不標出句子內部確切改了幾個字）
- 移動段落偵測（同一句子搬到別的位置，本次一律視為「原位置刪除＋新位置新增」）
- 批次多檔案比對
- 差異結果的版本歷史或雲端同步

> 上述功能明確排除於 Day3 MVP，避免範圍膨脹；若後續有需求再開新任務。

## 6. 非功能需求

- **隱私**：所有文字比對皆在瀏覽器端完成，內容不上傳、不送出任何網路請求
- **零依賴的例外**：本工具需內嵌 jsdiff 函式庫才能穩定處理各種文字差異邊界情況，是本系列少數不追求「絕對輕量單檔」的例外（沿用 Day2 對 pdf.js 的相同取捨邏輯），需在 README／文章中說明取捨原因
- **相容性**：Chrome／Safari／Edge 最新版正常運作；`file://` 協定下雙擊開啟需正常運作
- **效能**：單欄 1 萬字以內的文件比對需在使用者可接受的時間內完成

## 7. UI/UX 需求

- 上方：左右兩欄文字輸入區（含拖曳提示），下方或右上角「開始比對」按鈕
- 比對完成後：左右並排顯示差異結果，新增／刪除／修改用不同底色區分（需標示色彩圖例）
- 未變動區塊摺疊列，點擊可展開／收合；提供「全部展開」「全部收合」按鈕
- 頂部顯示差異統計摘要（新增／刪除／修改／未變動句數）
- 提供「複製摘要」「下載差異報告 MD」按鈕

## 8. 技術選型

- HTML + CSS + 原生 JavaScript + 內嵌 jsdiff（`diffArrays`，以句子陣列為比對單位）
- 斷句規則：先依 `\n\s*\n` 或單一 `\n` 分段，段落內再依 `。！？；` 切句，符號保留在句尾

## 9. 驗收標準（Acceptance Criteria）

1. 貼上兩份句子數相同但有 3 處修改的文字，比對結果需正確標出 3 處修改，其餘句子標示為未變動。
2. 貼上新版比舊版多出整段文字，多出的句子需標示為「新增」，不得誤判為修改。
3. 貼上新版比舊版少一段文字，缺少的句子需標示為「刪除」，不得誤判為修改。
4. 拖曳 .txt 檔案到左欄／右欄，需正確讀取檔案內容並帶入對應欄位。
5. 連續 3 句以上未變動的區塊，預設需摺疊顯示，點擊後可展開查看內容。
6. 點擊「下載差異報告 MD」需下載檔案，內容與畫面顯示的差異結果一致。
7. 開發者工具 Network 面板確認比對過程無任何對外請求。
8. 直接以 `file://` 方式雙擊開啟 HTML 檔，貼上文字並比對需正常運作。

## 10. Out of Scope

- 不處理句子搬移位置的偵測（一律視為刪除＋新增）
- 不做句子內部逐字元的精確差異標色
- 不支援批次多檔案一次比對
- 不處理英文縮寫句號（如 e.g.、Mr.）造成的斷句歧義，屬已知限制
- 不做雲端同步或版本歷史記錄

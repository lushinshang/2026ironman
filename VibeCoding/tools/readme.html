🛠️ Vibe Coding 獨立工具庫（Tools）

本目錄收錄 2026 iThome 鐵人賽 — Vibe Coding 系列所開發的 31 款純前端單檔（SPA）實用工具。

所有工具均遵循以下核心工程原則： 1. 零外部連線與伺服器依賴：所有 JavaScript、CSS 與演算法皆內嵌於單一 HTML，離線或斷網環境下 100% 可正常運作。 2. 資料全程不離開瀏覽器：所有文字、檔案、表格、圖片、程式碼與 PDF 皆於本機記憶體處理，絕不上傳至任何第三方伺服器。 3. 原檔永不覆寫：永遠產出全新處理後的檔案供下載，確保原始資料完整安全。

1. ✍️ 純文字與程式碼排版

檔案名稱 工具名稱 功能特色與適用情境
text-health-check.html 文字健檢工作台 即時統計字元數、全半形 CJK 字數、段落數與閱讀時間；檢查連續全半形空白、重複標點符號等排版問題，支援即時複製與匯出。
ai-text-cleaner.html AI 回答文字清理器 將 ChatGPT / Claude 回答中的 Markdown 標題語法、粗體、清單標記、程式碼區塊圍欄清理為適合直接貼入 Word / PPT / Email 的純淨排版。
filler-word-checker.html 贅詞與 AI 味檢查器 內建繁體中文常見贅詞庫與 AI 慣用語法特徵庫，偵測段落開頭同構句型與高頻空泛詞彙，提供逐項高亮與建議。
zh-tw-localizer.html 繁簡在地化轉換器 內嵌 OpenCC 繁簡對照與台灣在地化詞典（如「內存→記憶體」、「高清→高畫質」），多階段轉換，支援逐項審查接受或取消替換。
reversible-deidentifier.html 可逆式去識別化工具 以正規表示式與規則自動偵測姓名、手機、身分證號、Email 與關鍵詞，以 Token 進行遮蔽，支援匯出/載入對照表並可 100% 雙向還原。
text-diff.html 文字差異比對器 內嵌 jsdiff 引擎，支援按字元、詞彙、行進行雙欄或合併差異對照，中文標點斷句優化，自動摺疊大量未變動區塊。
python-code-formatter.html Python 離線排版器 內嵌 Pyodide (WASM CPython) 與官方 Black 排版庫、Prism.js 高亮，所有套件 Base64 內嵌並覆寫 fetch，純本機零網路執行 AST 語法格式化。

csv-pivot-dashboard.html CSV 樞紐圖表儀表板 純手寫 SVG 圖表渲染引擎（長條圖、折線圖、圓餅圖），支援多欄 Group By 與 SUM/COUNT/AVG 樞紐彙總，可一鍵匯出靜態快照。
csv-one-page-report.html CSV 一頁式管理報告 內建專為 A4 直式/橫式列印優化之排版版型，將 CSV 數據自動收斂為適合主管審閱之單頁 Summary 報表，可直接列印或另存 PDF。

4. 📑 PDF 專業工具集

檔案名稱 工具名稱 功能特色與適用情境

pdf-password-manager.html PDF 密碼管理器 基於 @cantoo/pdf-lib 實作，支援設定開啟密碼（User Password）與權限密碼（Owner Password），亦支援已知密碼之解密解除保護。
pdf-secure-redactor.html PDF 安全文字遮蔽 真正的像素級安全抹除：將遮蔽區域底層文字物件與矢量流物理移除後重新 Flatten 封裝，杜絕反白選取複製洩漏個資。
pdf-delivery-cleaner.html PDF 送件清理器 掃描並一鍵移除 PDF 內的作者資訊、軟體名稱、歷史註解（Annotations）、表單輸入暫存、附件與外部動作（Actions）。
office-content-publisher.html Office 內容發布排版器 將 Markdown 與 CSV 資料即時渲染為符合排版美學的 HTML 網頁文章或表格，支援一鍵複製富文字至 Word 或匯出獨立網頁。

🚀 離線使用方式

  1. 點擊任何 .html 檔案即可在任何現代瀏覽器（Chrome, Edge, Safari, Firefox）中直接打開使用。
  2. 亦可直接將特定工具複製到隨身碟或內部隔離網路環境，完全無需安裝 Node.js、Python 或任何伺服器環境。

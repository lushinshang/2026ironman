Day 1 PRD — 字數與段落統計器

交付類型：A 類（GitHub Pages／下載 HTML，純前端、零外部依賴、離線可用）

1. 背景與痛點

稿件、投稿、公告常有字數上限（例如 500 字摘要、1000 字投稿），但 Word／Google Docs 的「字數統計」對中英文混排、標點符號的計算方式不直覺，使用者常常送出後才發現超字數被退件。需要一個「貼上文字立即看到明確、可信賴數字」的小工具。

2. 目標使用者

一般辦公室行政人員、需要控管字數的投稿者／編輯，不具備程式背景。

3. 使用情境（User Story）

身為要投稿的使用者，我把稿件貼進工具，就能立刻知道「純文字字數」「含標點字數」「段落數」是否超過限制，不用等到送出後被退件。

4. 功能需求（MVP，本次必須完成）

# 功能 說明
F1 文字輸入區 <textarea>，貼上或直接輸入文字即時觸發統計
F2 中文字數 統計 CJK 字元數（不含標點、空白）
F3 英文單字數 以空白／標點分隔計算英文 word count
F4 總字數（含標點） 全部可見字元數（不含純空白換行）
F5 空白與換行數 分別統計空白字元數、換行（段落分隔）次數
F6 段落數 以連續空行分段，計算段落總數
F7 標點符號數 統計中英文標點符號總數
F8 即時更新 輸入時 debounce ≤ 150ms 內更新統計結果，不需按鈕
F9 一鍵清空 清空輸入內容並重置統計
F10 複製統計結果 一鍵複製「純文字字數：xx／段落：xx」格式的摘要文字
F11 自訂字數上限與超標警示 使用者輸入上限數字，超過時統計數字轉紅字並顯示進度條（進度條依「目前字數／上限」百分比填色，超過 100% 時整條變紅）
F12 匯出統計報告 一鍵匯出當前統計結果為 Markdown 或 CSV 檔（欄位：中文字數、英文字數、總字數、段落數、標點符號數、是否超標）
F13 下載本工具（離線使用） ⚠️ 後續新增（MVP 定案後追加，2026-08-08 commit 8d67d8b）：一鍵下載乾淨的獨立 HTML 副本，複製當前 DOM 並清空統計數字、超標警示與使用者輸入內容，移除頁面內的「返回首頁」相對連結後再序列化，確保下載檔可單獨離線開啟使用

5. 非必要／可延伸功能（Nice to have，非 Day1 範圍）

  • 中英文字數分開的歷史記錄（localStorage）

上述功能明確排除於 Day1 MVP，避免範圍膨脹；若後續有需求再開新任務。

6. 非功能需求

  • 零依賴：單一 HTML 檔，不載入任何外部 CDN／字型／JS 套件，可離線在瀏覽器直接開啟使用。
  • 隱私：所有計算在瀏覽器端完成，文字內容不上傳、不送出任何網路請求。
  • 效能：萬字內文字輸入，統計延遲需低於使用者可感知門檻（同 F8，≤150ms）。
  • 相容性：Chrome／Safari／Edge 最新版正常運作，響應式版面支援手機瀏覽。
  • 無障礙：輸入區與統計結果需有對應 label／aria-live，統計更新時螢幕報讀器可感知。

7. UI/UX 需求

  • 左側或上方：文字輸入區（大面積 textarea）
  • 右側或下方：統計卡片（純文字字數、英文字數、含標點總字數、段落數、標點符號數）
  • 統計卡片上方提供「自訂字數上限」輸入框；設定後顯示進度條，超過上限時統計數字與進度條轉紅字警示
  • 統計數字需大字體、一眼可辨識目前是否超過使用者自訂上限（若無上限則正常顯示）
  • 提供「清空」「複製摘要」「匯出 Markdown」「匯出 CSV」按鈕

8. 技術選型

  • HTML + CSS + 原生 JavaScript（不使用框架）
  • 中文字元判定：Unicode 範圍正則（CJK Unified Ideographs 等區段）
  • 不使用 Intl.Segmenter 以外的第三方分詞庫，避免外部依賴

9. 驗收標準（Acceptance Criteria）

  1. 貼上一段中英文混排文字（含標點、多段落），四項統計數字（中文字數／英文字數／總字數／段落數）人工核算需一致。
  2. 全空白／全換行輸入時，統計結果應為 0，不可出現 NaN 或錯誤。
  3. 開發者工具 Network 面板確認頁面載入與輸入過程中無任何對外請求。
  4. 直接以 file:// 方式雙擊開啟 HTML 檔，功能需正常運作（不依賴伺服器）。
  5. 手機瀏覽器（寬度 375px）版面不跑版、可正常輸入與複製。
  6. 設定字數上限後，輸入文字使總字數超過上限，統計數字與進度條需即時變紅；低於上限時維持一般樣式。
  7. 點擊「匯出 Markdown」「匯出 CSV」需各自下載一個檔案，內容包含當下所有統計欄位與是否超標的標記，欄位值需與畫面顯示數字一致。
  8. （F13，後續新增）點擊「下載本工具」下載出的 HTML 檔：不含使用者當下輸入的原始文字、不含任何 <a> 連結，並可在 file:// 下直接雙擊開啟正常運作。

10. Out of Scope

  • 不做多語言 UI 切換（僅繁體中文介面）
  • 不做雲端同步或帳號系統
  • 不處理檔案上傳（如 .docx／.pdf），僅純文字貼上

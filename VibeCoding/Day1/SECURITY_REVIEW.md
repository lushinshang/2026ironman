# Day 1 資安源碼檢測報告

**檢測日期**：2026-08-08
**檢測範圍**：`Day1/index.html`（新增檔案，純前端字數統計工具，無伺服器、無外部資源、無資料庫）
**方法**：逐行讀取全部原始碼，比對 OWASP 常見類別（XSS、注入、認證授權、加密、資料外洩），並比對前次 Playwright 驗收結果（頁面載入與操作過程中零對外網路請求）。

## 檢測結果：無發現高信心漏洞

| 類別 | 檢查結果 |
|---|---|
| XSS（反射/儲存/DOM-based） | 全程僅使用 `.textContent` 寫入畫面，無任何 `innerHTML`／`insertAdjacentHTML`／`document.write`，使用者輸入不會被當 HTML 解析 |
| Code Injection | 無 `eval`、`Function()`、動態 `<script>` 注入 |
| 資料外洩 | 無 `fetch`／`XMLHttpRequest`／`<img src>` 等對外請求；所有統計運算在本機記憶體完成 |
| CSV Injection（公式注入） | 匯出的 CSV／Markdown 內容只放入數字統計值與固定文字（「是」／「否」／「未設定上限」），使用者貼上的原始文字**不會**被寫入匯出檔案，不存在 `=cmd|...` 類公式注入風險 |
| 檔案下載（Blob + `<a download>`） | 檔名為程式碼寫死的固定字串（`字數統計報告.md`/`.csv`），非使用者可控，無路徑穿越風險 |
| 認證／授權 | 不適用（純客端靜態工具，無登入、無權限邊界） |
| 儲存敏感資料 | 無 `localStorage`／`cookie`／任何持久化儲存 |
| 剪貼簿 API | `navigator.clipboard.writeText` 使用方式正確，有 feature-detect 與例外處理，不影響安全性 |

## 結論

`Day1/index.html` 未發現 HIGH 或 MEDIUM 等級安全漏洞。程式碼架構本身（無 `innerHTML`、無外部請求、匯出內容不含原始使用者文字）已規避此類單頁小工具最常見的 XSS 與資料外洩風險類型，符合 PRD 訂下的「零依賴、隱私、離線可用」非功能需求。

## 補充檢測：「下載本工具」離線功能（後續新增，2026-08-08 commit `8d67d8b`）

> ⚠️ 此功能於本報告首次撰寫**之後**才追加，原檢測範圍未涵蓋，故另外補測。

**檢測對象**：`buildCleanHtmlCopy()`（`index.html` 約 463~493 行），使用 `document.documentElement.cloneNode(true)` 複製整份 DOM 後序列化為可下載的 HTML 檔。

| 類別 | 檢查結果 |
|---|---|
| 使用者輸入外洩 | `<textarea id="text-input">` 標籤內無預設文字節點，使用者輸入僅存在 `.value` 屬性；`cloneNode`／`outerHTML` 不會序列化 `.value`，故下載檔不含使用者貼上過的原始文字 |
| 殘留動態狀態 | 複製後另外手動清空統計數字（`stat-*` 各欄位重設為 `0`）、進度條樣式與 `over` 樣式、toast 訊息，避免下載檔帶著上次操作的畫面殘影 |
| 失效連結 | 複製前主動移除 `.nav-back`（返回首頁）節點；此連結為站內相對路徑，下載到其他資料夾後會失效，違反「單檔可離線獨立使用」前提，故整個移除 |
| 檔名／路徑穿越 | 下載檔名為程式碼寫死的固定字串（`字數統計器.html`），非使用者可控，無路徑穿越風險 |

**補充結論**：此功能同樣未發現 HIGH 或 MEDIUM 等級安全漏洞，且符合 PRD F13 訂下的「不含使用者輸入、不含站內連結、可離線獨立開啟」驗收標準。

公開資訊變更雷達

資料來源：iThome RSS。GitHub Actions 每小時檢查一次，有新文章才建立紀錄與 GitHub Issue 通知，沒有變化的檢查不會留下任何痕跡——這是一個安靜的雷達，不是每天固定產出的報表。

這是網站，不是離線 HTML。需透過網站瀏覽（讀取伺服器上的 data/history.jsonl）， 不支援下載後單獨離線使用——資料由 GitHub Actions 自動更新，離線下載無法重現這個能力。

資料來源：iThome RSS（https://www.ithome.com.tw/rss.xml），本站為非官方整理呈現，僅供技術練習展示（GitHub Actions 排程 + Repo 即 State + Diff 通知），非商用、非官方轉載。

機制：每小時抓取一次 RSS，比對前一次留下的 seen.json（以文章 guid 判斷是否為新文章），有新文章才建立一張彙總 GitHub Issue 並在此頁面留下一筆時間軸紀錄；沒有新文章的檢查不會產生任何內容，避免無意義的重複版本。

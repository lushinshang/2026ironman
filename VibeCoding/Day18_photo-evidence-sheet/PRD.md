# PRD 16 — 照片 → 工作成果附件
- **英文短名稱**：`photo-evidence-sheet`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/photo-evidence-sheet/`

### 為什麼做
活動、施工、教育訓練與設備安裝後，整理大量照片成正式成果附件很耗時。

### MVP
- 多照片匯入。
- 拖曳排序。
- 圖說。
- 每頁 2/4/6 張。
- 自動編號。
- 標題、日期、地點欄。
- A4 預覽。
- 匯出列印版 HTML / PDF。
- 不覆寫原始照片。

### 驗收條件
- 情境：20 張照片可套固定版型。
- 情境：重新排序後圖說仍與照片綁定。
- 情境：列印時照片不超出版面。

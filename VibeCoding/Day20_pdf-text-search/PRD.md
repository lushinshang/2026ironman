# PRD 03 — PDF 文字擷取與全文搜尋
- **英文短名稱**：`pdf-text-search`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-text-search/`

### 為什麼做
長篇 PDF 文件（規章、手冊、報告）往往難以快速檢閱或匯出純文字。使用者需要一個在瀏覽器本地即時擷取全書文字、進行全文搜尋定位並支援匯出 TXT/Markdown 的輕量工具。

### MVP
- 上傳多頁文字層 PDF。
- 逐頁擷取純文字並結構化呈現。
- 全文搜尋輸入框（防抖 150ms），大小寫不敏感匹配，顯示命中頁碼與前後 30 字元片段。
- 點擊搜尋結果平滑捲動並高亮該頁文字區塊。
- 支援文字層缺失偵測提示（若為純掃描檔提示無文字層）。
- 匯出 TXT、匯出 Markdown、一鍵複製全部純文字。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：有文字層 PDF 可搜尋並列出頁碼。
- 情境：掃描 PDF 無文字層時明確提示限制。
- 情境：匯出文字與可擷取內容一致。

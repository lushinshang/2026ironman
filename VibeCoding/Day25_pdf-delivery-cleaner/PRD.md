# PRD 23 — PDF 對外交付清理器
- **英文短名稱**：`pdf-delivery-cleaner`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-delivery-cleaner/`

### 為什麼做
向外部客戶、公家機關或投標單位發送 PDF 文件前，需移除檔案中的作者資訊、內部連結、審閱留言、表單欄位、內嵌附件與執行腳本，避免機密與內部資訊外流。

### MVP
- 上傳單一 PDF 檔案。
- 自動掃描 6 大類對外風險項目：
  1. 文件屬性（Metadata / XMP）：作者、公司、軟體、修改時間等。
  2. 超連結（Link Annotations）：外部網址、內部系統路徑、mailto。
  3. 註解與註記（Comments / Markups）：審閱便條、螢光筆畫記、彈出註解。
  4. 表單欄位（AcroForm / Fields）：互動式填表欄位與資料。
  5. 內嵌附件（Embedded Files）：隨檔夾帶的 Word、Excel、壓縮檔。
  6. 動作與腳本（Actions / JavaScript）：開啟動作、自動化腳本。
- 若無任何可清理項目，顯示明確安心結果。
- 支援個別勾選清理項目（只清所選，未選項目原樣保留）。
- 產出清理前後對照表。
- 匯出下載固定檔名 `clean-for-delivery.pdf`。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：沒有可清理項目時顯示明確結果。
- 情境：只選 Metadata 時不順便移除其他物件。
- 情境：輸出後重新掃描，已選清除項目應消失。
- 情境：清理過程不影響頁面視覺內容，頁數與畫面渲染保持一致。

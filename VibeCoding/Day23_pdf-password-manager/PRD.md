# PRD 22 — PDF 密碼管理器
- **英文短名稱**：`pdf-password-manager`
- **類型**：新功能
- **部署型態**：單一 HTML / GitHub Pages，可離線
- **AI**：否
- **SDD**：`sdd/pdf-password-manager/`

### 為什麼做
公司薪資單、扣繳憑單、電子帳單常預設設定身分證字號為密碼；分發前需移除密碼或批次替多份機密報告加上專屬密碼。

### MVP
- 支援批次匯入多份 PDF 檔案。
- 提供三種操作模式：
  1. 解鎖／移除密碼（輸入舊密碼轉為無密碼 PDF）。
  2. 設定新密碼（為未加密 PDF 設定開啟密碼）。
  3. 更換密碼（輸入舊密碼並設定新密碼）。
- 批次處理容錯：單一檔案失敗不中斷其他檔案處理。
- 支援個別下載與一鍵打包成功項目為 ZIP。
- 密碼安全：密碼不儲存至持久化媒介，複製摘要不洩漏密碼。
- 純前端執行，檔案不上傳伺服器。

### 驗收條件
- 情境：正確密碼可解鎖支援格式的 PDF。
- 情境：錯誤密碼不能產生假成功結果。
- 情境：重新加密後，開啟輸出檔需要新密碼。

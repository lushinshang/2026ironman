## PRD A2 — 文字差異比對器

> 補記：v2 需求基線（`2026-ironman-vibecoding-30-prd.md`）30 題清單漏收此題（v1 Day7，原始編號 Day3，因系列重新分類移入）。本檔案為補寫的 PRD，格式對齊基線內 PRD 03、PRD 04。編號採 `PRD A2`（A 代表 Additional／附加，明確不佔用基線 01-30 既有序號），與另一補回題 `PRD A1`（`filler-word-checker`）並列，不代表兩者在基線中的相對位置；與 `shared/CONTRACT.md` 第 5 節既有的 `Day07 text-diff` 對應。

- **英文短名稱**：`text-diff`
- **類型**：新功能（v1 補回，原 v1 Day3／Day7）
- **部署型態**：單一 HTML / GitHub Pages，可離線（唯一例外：需內嵌第三方 jsdiff 函式庫才能離線運作，不上傳任何內容到伺服器）
- **AI**：否
- **SDD**：`sdd/text-diff/`

### 為什麼做

承辦人員收到合約、公文修訂版時，兩份文件內容相近但改了幾處條款，肉眼逐字比對容易漏看也容易看錯。若原始檔案是 PDF，通常先用其他轉檔工具轉成乾淨純文字，再貼進本工具比對兩版差異；若想先做字數統計與格式問題檢查，可另外搭配 `text-health-check`（Day01，文字健檢工作台，僅健檢不修改原文）。規章、公告、SOP 等文件每次修訂後也有相同的版本比對需求。

### 輸入

左右兩欄分別貼上「舊版」「新版」文字；或各自拖曳單一 .txt / .md 檔案帶入對應欄位。

### MVP

- 雙欄文字輸入（左「舊版」、右「新版」），皆可直接貼上。
- 左右兩欄各自支援拖曳單一 .txt 或 .md 檔案，自動讀取內容帶入該欄。
- 逐句斷句：先依空行（`\n\s*\n`，即兩個以上連續換行、中間可含空白）切分段落；段落內部若還有單一 `\n`（無空行的換行，例如手動折行），視為段落內的普通空白，先正規化為半形空白再往下處理，不當作段落邊界。段落內再依中文句尾標點（。！？；）分句；無標點的整段視為一句。
- 用內嵌 jsdiff 函式庫（`diffArrays`）對兩份句子陣列做差異比對，標出新增、刪除、修改。修改的配對規則：`diffArrays` 輸出中，連續 N 句「刪除」緊接著連續 M 句「新增」的區段，依出現順序逐一配對（第 1 句刪除配第 1 句新增、第 2 句配第 2 句……），配到 `min(N, M)` 對為止，各對標示為「修改」；若 N＞M，多出的 `N－M` 句刪除維持標示為「刪除」（排在配對區段之後）；若 M＞N，多出的 `M－N` 句新增維持標示為「新增」（排在配對區段之後）。
- 並排左右對照顯示，逐句對齊；新增／刪除／修改以不同底色標示，並提供色彩圖例。
- 連續未變動句數 ≥3 句的區塊（達到 3 句本身就觸發，不必超過 3 句），預設摺疊為一行「未變動 N 句（點擊展開）」，可個別展開或一鍵全部展開／收合。
- 差異統計摘要：新增 X 句／刪除 X 句／修改 X 句／未變動 X 句。
- 複製差異摘要文字；下載 Markdown 格式的差異報告。
- 下載本工具離線版（`buildCleanHtmlCopy()`，依 `shared/CONTRACT.md` 第 6 節 Level 1 共通 UI 基線，清空雙欄輸入與比對結果，移除返回連結）。
- 內嵌 jsdiff 的版本與授權（BSD-3-Clause）標示於頁面上可見處，依 `shared/CONTRACT.md` 第 4 節規定。

### 不做

句子搬移位置偵測（一律視為刪除＋新增）、句內字元級差異精確標色（僅整句標色）、批次多檔案比對、差異結果的版本歷史或雲端同步、英文縮寫句號（如 e.g.、Mr.）造成的斷句歧義處理、下載 HTML/CSV 格式報告（v1 後續迭代功能，非本次 MVP 範圍）。

### 驗收條件

- 情境：當貼上兩份句子數相同但有 3 處修改的文字並執行比對，就會看到 3 處被標示為修改，其餘句子標示為未變動。
- 情境：當新版比舊版多出整段文字並執行比對，就會看到多出的句子標示為「新增」，不會被誤判為修改。
- 情境：當新版比舊版少一段文字並執行比對，就會看到缺少的句子標示為「刪除」，不會被誤判為修改。
- 情境：當拖曳 .txt 或 .md 檔案到左欄或右欄，就會正確讀取檔案內容並帶入對應欄位。
- 情境：當有連續未變動句數 ≥3 句的區塊時執行比對，就會看到該區塊預設摺疊，點擊後可展開查看內容。
- 情境：當點擊「下載差異報告 MD」，就會下載檔案，內容與畫面顯示的差異結果一致。
- 情境：當比對完成後檢視頁面，就會在可見處看到 jsdiff 的版本號與 BSD-3-Clause 授權標示。
- 情境：以 `file://` 方式雙擊開啟 HTML 檔，貼上文字並執行比對，就會正常運作。
- 情境：貼上兩欄文字並執行比對後，點擊「下載本工具離線版」，下載的 HTML 檔案中雙欄輸入框與比對結果皆為空白，不含剛才輸入或比對出的任何資料，且不含返回連結。

### 邊界情況

- 情境：當兩欄皆為空白時執行比對，就不會報錯或整頁崩潰，統計摘要顯示新增／刪除／修改／未變動皆為 0。
- 情境：當兩欄文字完全相同時執行比對，就會看到全部句子標示為未變動，新增／刪除／修改皆為 0。
- 情境：當一欄為空、另一欄有內容時執行比對，就會看到有內容的一欄全部句子標示為新增（或刪除，視空白欄位是舊版或新版而定），不會誤判為修改。
- 情境：當貼上一段沒有任何句尾標點的超長文字（例如上千字的整段）並執行比對，就會將整段視為一句進行比對，不會拆分過細，也不會卡死或無回應。

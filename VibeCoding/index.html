📅 1. 交付優先順序

優先級 交付方式 適用情境
A GitHub Pages／下載 HTML 靜態工具，使用者拖入檔案、貼上文字、點擊按鈕即可在瀏覽器內純前端完成，個資不外洩。
B Colab Python 腳本 (.ipynb) 適用於 PDF 批次處理、OCR、語音轉文字、影像處理與大型資料分析等需要重度運算之情事。
C Colab 終端機指令 適用於 ffmpeg 批次影音處理、格式轉換、大型檔案批次改名等命令列操作。
D 跨平台指令產生器 網頁產生安全指令（預先顯示 dry-run），使用者自行貼到 macOS/Windows/Linux 終端機執行。

🛠️ 2. 重要設計原則

  • 離線與零依賴 (A 類)：HTML 工具盡量做成「單一檔案、零外部庫載入依賴、可離線使用」。
  • 雲端隱私安全 (B、C 類)：Colab 腳本提供「上傳 ➡️ 執行 ➡️ 下載」流程，且必須顯眼標示「資料會上傳到 Colab/Google 雲端運作，敏感資料請本機運行」。
  • 防呆與可逆性：指令工具不直接刪除或覆寫檔案，預設提供 dry-run 預覽，並提供還原/撤銷資訊。
  • 通用性：不限制只服務行政人員，而是讓一般使用者、行政人員與開發人員都能輕易上手。

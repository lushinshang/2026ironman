# Tasks：Day8 異動清單雜訊過濾

- [x] T1 新增雜訊判斷函式：內容過長（150 字門檻）、重複案號/頁碼特徵、old/new 字元重疊率過低（15% 門檻）三項規則，任一命中回傳 true
- [x] T2 解析階段（`parseDiffReport` 或其呼叫點）為每條異動加上 `suspicious` 標記，命中雜訊判斷者預設 `checked: false`，其餘維持預設全選
- [x] T3 清單渲染：可疑項目加上視覺提示（例如淡化底色＋「可能為雜訊」文字標籤），不影響使用者手動勾選/取消勾選的既有互動
- [x] T4 統計摘要新增「可疑雜訊：N 條（已預設不勾選）」一行，即時反映目前解析結果
- [x] T5 Playwright 實測：用使用者提供的真實測試片段（含雜訊案例）貼入，確認可疑項目正確預設不勾選、正常項目維持勾選、統計數字正確；`python3 -m html.parser` 驗證語法；確認既有全選/全不選/摘要預覽/複製/下載功能未受影響（回歸測試）——fresh agent 獨立驗收 11 條條件全數通過

## 驗收條件

- 情境：當貼上含「AB12345C」重複案號雜訊的段落並解析，就會看到該條在清單中標示可疑，且預設未勾選。
- 情境：當貼上一條 old/new 文字幾乎完全不相關（字元重疊率極低）的「修改」項目，就會被標記為可疑並預設不勾選。
- 情境：當貼上一條正常、簡短、內容相關的異動，就不會被誤標為可疑，維持預設勾選。
- 情境：當使用者手動勾選一條被標記為可疑的項目，就會正常納入摘要預覽，不受過濾邏輯阻擋。
- 情境：當統計摘要顯示時，就會包含「可疑雜訊：N 條」且數字與清單中標示可疑的條數一致。
- 情境：當重新執行既有的全選/全不選/複製/下載測試，就會維持原本行為不變（無回歸）。

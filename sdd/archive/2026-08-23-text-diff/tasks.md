## 驗收條件

- 情境：當貼上兩份句子數相同但有 3 處修改的文字並點擊「開始比對」，就會看到 3 處被標示為修改，其餘句子標示為未變動。
- 情境：當新版比舊版多出整段文字並點擊「開始比對」，就會看到多出的句子標示為「新增」，不會被誤判為修改。
- 情境：當新版比舊版少一段文字並點擊「開始比對」，就會看到缺少的句子標示為「刪除」，不會被誤判為修改。
- 情境：當拖曳 .txt 或 .md 檔案到左欄或右欄，就會正確讀取檔案內容並帶入對應欄位。
- 情境：當有連續未變動句數 ≥3 句的區塊並點擊「開始比對」，就會看到該區塊預設摺疊，點擊後可展開查看內容。
- 情境：當點擊「下載差異報告 MD」，就會下載檔案，內容與畫面顯示的差異結果一致。
- 情境：當比對完成後檢視頁面，就會在可見處看到 jsdiff 的版本號與 BSD-3-Clause 授權標示。
- 情境：以 `file://` 方式雙擊開啟 HTML 檔，貼上文字並點擊「開始比對」，就會正常運作，Network 面板無對外請求。
- 情境：貼上兩欄文字並點擊「開始比對」後，點擊「下載本工具離線版」，下載的 HTML 檔案中雙欄輸入框與比對結果皆為空白，不含剛才輸入或比對出的任何資料，且不含返回連結。
- 情境：當兩欄皆為空白時點擊「開始比對」，就不會報錯或整頁崩潰，統計摘要顯示新增／刪除／修改／未變動皆為 0。
- 情境：當兩欄文字完全相同時點擊「開始比對」，就會看到全部句子標示為未變動，新增／刪除／修改皆為 0。
- 情境：當一欄為空、另一欄有內容時點擊「開始比對」，就會看到有內容的一欄全部句子標示為新增或刪除，不會誤判為修改。
- 情境：當貼上一段沒有任何句尾標點的超長文字（例如上千字整段）並點擊「開始比對」，就會將整段視為一句進行比對，不會拆分過細，也不會卡死或無回應。

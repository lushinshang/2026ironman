# 設計方向：VibeCoding 作品集入口頁

## 題材與工作

- 題材：「想 → 說 → 對 → 做」四層對齊的 Vibe Coding 系列，28 個單檔 HTML 工具（Day01–Day30）。
- 讀者：iThome 讀者、想直接試用工具的人。
- 首頁的工作：一眼講出「對齊」這個主張，然後讓人快速找到並打開想用的工具。

## 唯一的記憶點：套版（off-register 印刷）

「對齊」在印刷裡有現成的語彙：套版。四色版沒對準會露出色邊，對準了就疊成一個黑字。
Hero 的「想 說 對 做」每個字由四層（青／洋紅／黃／墨）疊印，載入時從錯位滑到對準，只播一次；其餘頁面保持安靜。
Hover 一個作品時，作品名稱產生輕微錯位色邊，離開就對準，回饋跟主題同一個語彙。

## Token

| 角色 | 淺色 | 深色 |
|---|---|---|
| 紙 | `#EDEFF1`（偏冷灰白，非米色） | `#101215` |
| 墨 | `#15171B` | `#E9ECEF` |
| 青版 | `#00A6D0` | `#19C1E8` |
| 洋紅版 | `#E8307F` | `#FF5C9D` |
| 黃版 | `#F7C600` | `#FFD43B` |
| 文字強調（青／洋紅，需 4.5:1） | `#00698A`／`#B0155D` | `#5CD3F2`／`#FF8DB9` |

疊印用 `mix-blend-mode: multiply`（深色用 `screen`）；`mix-blend-mode` 在 `file://` 可用。
**對比保證**：疊印只用在 Hero 大字（decorative，真實文字在 `aria-label`／同位置的 `<h1>` 墨色層）；所有小字一律用墨色與強調文字色。

## 字型

只用系統字型，不引任何網路字型（離線、零外部請求）。
單一家族：`"PingFang TC","Noto Sans TC","Microsoft JhengHei",system-ui,sans-serif`。
Hero 用 900 字重超大字；內文 400／500；作品名 700。不使用等寬字型標籤、不使用全大寫標籤。
字級（clamp，流體）：hero `clamp(4.5rem,18vw,15rem)`、h2 `clamp(1.5rem,3vw,2.25rem)`、作品名 `1.125rem`、說明 `0.95rem`、內文行高 1.7、行長 ≤ 38 全形字。

- 對齊：Hero 與內容左對齊；左欄群組標籤 sticky，右欄為列。窄螢幕改單欄，群組標籤變成區塊標題。
- 列取代卡片：每列＝Day 編號（真實序列，所以保留）＋名稱＋說明，整列是一個 `<a>`，列間用細分隔線，沒有圓角卡片與陰影。

## 動態語彙

1. 載入時 Hero 疊印對準（約 1.1s，單次）。
2. Hover／focus 列：名稱色邊錯位 2px 再回正（0.18s）。
3. 篩選／搜尋：列以 `hidden` 切換，沒有轉場（立即回饋）。
4. 無捲動揭露、無視差、無持續動畫。`prefers-reduced-motion`：直接顯示對準狀態，hover 只換底線。

## 自我審查：對照「通用預設」後修掉的部分

| 初稿 | 為何是預設 | 改成 |
|---|---|---|
| 米色紙＋襯線標題＋陶土色 | 常見 AI 生成配色 | 冷灰白紙＋四個印刷版色，由題材（套版）推出 |
| 28 張同樣的圓角卡片 | SaaS 卡片組 | 左欄群組標籤＋整列連結 |
| 每個標題上方加全大寫小標 | 範本化裝飾 | 完全不用 |
| 連結尾巴加「→」 | 範本化裝飾 | 不加，用整列 hover 錯位表示可點 |
| 每區塊淡入上滑 | 通用動畫 | 全頁只有 Hero 一次動態 |
| 日期／編號用等寬字 | 範本化 | 同一家族，用字重區分 |

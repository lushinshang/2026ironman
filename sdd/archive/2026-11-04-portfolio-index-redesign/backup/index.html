VibeCoding 作品集

Vibe Coding 不是隨想隨做，而是把腦中的想法，一步一步和自己的表達、AI 的理解、最後做出的產品對齊：想 → 說 → 對 → 做。

30 天挑戰中，每天用這套對齊方法做出一個零依賴、單檔 HTML 的文字處理小工具。以下是已完成上線的作品。

Day01

文字健檢工作台

中英文字數、標點空白統計、連續空白與重複標點偵測、過長段落提示。

 Day02

AI 回答 → Office 文字清理器

清掉 Markdown 標記、emoji、分隔線，輸出 Word／Email／純文字三種模式。

 Day03

贅詞與 AI 味檢查器

詞庫比對、詞頻統計、段落開頭同構偵測，詞庫可編輯匯入匯出。

 Day04

繁簡與台灣在地化轉換器

內嵌 OpenCC 詞典做簡繁轉換與台灣用語替換，可逐項接受／取消。

 Day05–06

可逆式文字去識別化

個資 Token 化並產生 mapping，可用 mapping 在本機還原。

 Day07

文字差異比對器

逐句比對兩份文字，刪除與新增配對成「修改」，未變動區塊摺疊。

 Day08

CSV Doctor & Cleaner

編碼與分隔符偵測、欄數不齊與型別混雜健檢，逐項確認後匯出乾淨 CSV。

 Day09

兩期清冊異動報告

兩份 CSV 以主鍵比對，列出新增、刪除與欄位異動，可匯出異動清單。

 Day10

總表 → 分單位批次拆檔

依指定欄位把總表拆成多份 CSV，一次打包成 ZIP 下載，檔名自動淨化。

 Day11–12

CSV Pivot Dashboard

多欄 Group By 與彙總管線，手寫 SVG 長條／折線／圓餅圖，可匯出靜態快照儀表板。

 Day13

CSV 一頁式管理報告

KPI 卡片、Top5/Bottom5、占比與趨勢彙整成單頁報告，A4 列印分頁與 SVG 相容版型。

 Day14

圖片批次最佳化工作台

等比例縮放、品質壓縮二分逼近、批次處理與打包 ZIP 下載。

 Day15

EXIF 隱私檢查與清除

解析 JPEG APP1 二進位標籤、四級隱私風險提示、無損剔除 EXIF/XMP 與前後對照。

 Day16

Screenshot Privacy Sanitizer

支援黑箱、馬賽克與模糊三種底層像素抹除，具備可撤銷操作管線與 Before/After 防呆。

 Day17

文件照片透視校正器

四角拖曳對齊、高斯消去法求解單應性矩陣、雙線性插值校正與黑白灰階增強。

 Day18

工作成果照片附件產生器

大批次匯入照片、原子綁定圖說排序、2/4/6 張 A4 分頁與標準列印版面輸出。

 Day19

PDF 轉 JPG 批次工具

逐頁 2.0x 高解析渲染轉 JPG、品質壓縮滑桿、非同步進度條與 ZIP 打包下載。

 Day20

PDF 文字擷取與全文搜尋

多頁文字層抽取、150ms 防抖全文搜尋、關鍵字高亮跳轉與 TXT/MD/剪貼簿匯出。

 Day21

PDF 拆分 / 合併 / 重排

多檔匯入、原生拖曳重排、90° 順時針旋轉、標記刪除還原、多輸出群組分派與 ZIP 打包。

 Day22

PDF 頁碼 / 浮水印 / 送審章

完整內嵌 Noto Sans TC 中文字型、頁首尾頁碼、四種預設送審章與角度位置自訂預覽。

 Day23

PDF 密碼管理器

批次解鎖、設定密碼、更換密碼三大模式，明碼/遮罩切換、零持久化洩密防禦與容錯處理。

 Day24

PDF 安全遮蔽 / 選擇性點陣化

互動式矩形遮蔽框選、選擇性點陣化徹底銷毀底層文字層、未遮蔽頁向量 100% 原樣保留。

 Day25

PDF 對外交付清理器

6 大類對外風險物件自動掃描、選擇性清洗、前後對照表、安心零風險提示與固定檔名交付。

 Day26

Office Content Publisher

Markdown/TXT 筆記與 CSV 數據雙模式發布、型別感知智慧排序、獨立網頁匯出與乾淨列印。

 Day27

Document Tools 重製版

圖片互轉/Resize/壓縮、PDF 合併/拆分/轉圖、Markdown 編輯預覽輸出，整合前 26 天模組的壓軸產品。

 Day28

每日自動更新工作 Dashboard

GitHub Actions 排程抓取聯合信用卡中心信用卡盜刷詐欺月統計、Repo 即資料庫、本月摘要卡片（可切換單一詐欺型態）、手刻 SVG 趨勢圖，不可下載離線使用。

 Day29

公開資訊變更雷達

每 6 小時巡一次 iThome RSS，有新文章才建立通知，沒有變化就不留紀錄；用 GitHub Issue 當通知信箱，免額外金鑰。

 Day30

Office 文件隱私 Metadata 清除工具

DOCX/XLSX/PPTX 三格式的作者/公司/註解/內嵌縮圖/樞紐分析表快取/裁切圖片原圖殘留一鍵清除，PowerPoint 裁切圖片改用 Canvas 燒進像素，不只是刪除裁切標記。
